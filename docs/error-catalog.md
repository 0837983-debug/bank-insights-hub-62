# Карта ошибок (Error Catalog)

Единая система ошибок приложения Bank Insights Hub.

## Принципы

1. **На веб-интерфейс никогда не попадают сырые ошибки сервера.**
2. Каждая ошибка имеет **машиночитаемый код** (перечисление `AppErrorCode`).
3. Коду соответствует **человекочитаемое сообщение на русском языке** (без терминов).
4. Все ошибки создаются через класс `AppError` и обрабатываются **единым центром** — `errorHandler`.

## Архитектура

- `backend/src/types/errors.ts` — перечисление `AppErrorCode`, карта `ERROR_CATALOG`, класс `AppError`, утилита `mapBuilderError`.
- `backend/src/middleware/errorHandler.ts` — единый центр обработки всех ошибок.
- Ответ с ошибкой имеет вид: `{ code, message, details? }` (details — только в режиме разработки).
- Детали/причина ошибки пишутся в логи сервера и не уходят клиенту.

## Перечень кодов

### Авторизация (AUTH)

| Код | HTTP | Сообщение | Описание |
|-----|------|-----------|----------|
| `AUTH_INVALID_CREDENTIALS` | 401 | Неверное имя пользователя или пароль | Неверный логин или пароль |
| `AUTH_UNAUTHORIZED` | 401 | Требуется авторизация | Запрос без токена доступа |
| `AUTH_TOKEN_EXPIRED` | 401 | Сессия истекла. Войдите заново | Токен недействителен или истёк |
| `AUTH_USER_BLOCKED` | 401 | Учётная запись не найдена или заблокирована | Пользователь отсутствует или заблокирован |
| `AUTH_REFRESH_MISSING` | 401 | Отсутствует токен обновления сессии | Refresh-токен не передан |
| `AUTH_FORBIDDEN` | 403 | Недостаточно прав для выполнения действия | У пользователя нет нужной роли |
| `AUTH_RATE_LIMITED` | 429 | Слишком много попыток. Попробуйте позже | Превышено число попыток входа |

### Пользователи (USER)

| Код | HTTP | Сообщение | Описание |
|-----|------|-----------|----------|
| `USER_REQUIRED_FIELD` | 400 | Не все обязательные поля заполнены | Обязательный параметр не передан |
| `USER_INVALID_ROLE` | 400 | Указана недопустимая роль | Роль вне списка разрешённых |
| `USER_SUPER_ADMIN_FORBIDDEN` | 400 | Создание супер-администратора через интерфейс запрещено | Защита от эскалации прав |
| `USER_ALREADY_EXISTS` | 409 | Пользователь с таким именем уже существует | Имя занято |
| `USER_NOT_FOUND` | 404 | Пользователь не найден | Пользователь отсутствует |
| `USER_SELF_ACTION` | 400 | Нельзя выполнить это действие над самим собой | Запрет действий над собой |
| `USER_ACTIVE_REQUIRED` | 400 | Не передан статус учётной записи | Поле isActive обязательно |

### Загрузка файлов (UPLOAD)

| Код | HTTP | Сообщение | Описание |
|-----|------|-----------|----------|
| `UPLOAD_NO_FILE` | 400 | Файл не был загружен | В запросе нет файла |
| `UPLOAD_EMPTY` | 400 | Загруженный файл пустой | Файл без данных |
| `UPLOAD_SIZE_EXCEEDED` | 400 | Размер файла превышает максимально допустимый | Файл больше 50 МБ |
| `UPLOAD_COUNT_INVALID` | 400 | Неверное количество файлов | Ожидается один файл |
| `UPLOAD_BAD_FORMAT` | 400 | Файл должен быть в формате XLSX | Неподдерживаемый формат |
| `UPLOAD_PROCESSING` | 400 | Не удалось обработать файл | Ошибка разбора/сохранения |
| `UPLOAD_NOT_FOUND` | 404 | Загрузка не найдена | Загрузка отсутствует |
| `UPLOAD_PARAM_REQUIRED` | 400 | Не передан обязательный параметр | Параметр запроса отсутствует |

### Данные и запросы (QUERY)

| Код | HTTP | Сообщение | Описание |
|-----|------|-----------|----------|
| `QUERY_INVALID_PARAMS` | 400 | Неверные параметры запроса | Параметры не прошли проверку |
| `QUERY_INVALID_CONFIG` | 400 | Некорректная конфигурация запроса | Конфигурация недействительна |
| `QUERY_MAPPING_INCOMPLETE` | 400 | Отсутствуют обязательные поля в маппинге | Маппинг неполный |

### Прочее

| Код | HTTP | Сообщение | Описание |
|-----|------|-----------|----------|
| `VALIDATION_FAILED` | 400 | Проверьте введённые данные | Данные не прошли валидацию |
| `NOT_FOUND_ROUTE` | 404 | Запрашиваемая страница или адрес не найдены | Маршрут не существует |
| `NOT_FOUND_DATA` | 404 | Данные не найдены | Данные отсутствуют |
| `INTERNAL` | 500 | Произошла ошибка на сервере. Попробуйте позже | Непредвиденная внутренняя ошибка |

## Использование в коде

```ts
import { AppError, AppErrorCode } from "../types/errors.js";

// Бросить ошибку из карты
throw new AppError(AppErrorCode.AUTH_INVALID_CREDENTIALS);

// В Express-маршруте передать ошибку в единый обработчик
catch (error) {
  next(error); // errorHandler сам подберёт код и сообщение
}
```

## Добавление новой ошибки

1. Добавить элемент в enum `AppErrorCode` (категория префиксом, например `UPLOAD_*`).
2. Добавить запись в `ERROR_CATALOG` (HTTP-статус, сообщение, описание).
3. Внести строку в этот документ.
4. Использовать через `throw new AppError(AppErrorCode.НОВЫЙ_КОД)`.
