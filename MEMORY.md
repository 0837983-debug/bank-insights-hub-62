# MEMORY

Ключевые сведения, которые необходимо помнить при работе с данным репозиторием.

## Ежедневные отчёты
- Каждый рабочий день записывать работу в отдельный текстовый файл внутри папки `daily-reports/`.
- Имя файла — дата дня в формате `ДД-ММ-ГГГГ.txt` (например, `07-08-2026.txt`).
- Файлы ведутся в едином формате: «ОТЧЁТ О РАБОТЕ ЗА ...», разделы по пунктам.
- После создания/правки отчётов сверять содержимое и при необходимости перечитывать файлы.

## Краткая хронология
- 06.08.2026 — поездка в банк (полдня), подписаны документы на трудоустройство; получен доступ к репозиторию/проекту; проведён анализ программы, поиск недочётов, составлен план, оценка сроков; созданы PROJECT_ANALYSIS_AND_PLAN.md и PROJECT_SUMMARY.txt.
- 07.08.2026 — несколько обращений в техподдержку; настройка VPN Cisco; получение доступов к банковскому контуру.
- 10.08.2026 — выделено место на удалённом сервере; запрос в техподдержку на 2 сервера (тестовый и производственный стенды); клонирован репозиторий; запущены проект и контейнеры; установлены зависимости и скачаны образы; настроен ИИ для разработки; дополнительный анализ проекта и настройка портов (избежание коллизий).

## Основные файлы
- PROJECT_ANALYSIS_AND_PLAN.md — детальный анализ программы и план работ.
- PROJECT_SUMMARY.txt — сводная информация по проекту.
- MEMORY.md — данный файл, хранит ключевые сведения.

## Обслуживание памяти
- Периодически очищать память от устаревшей информации: удалять завершённые/неактуальные детали, оставляя только важное для продолжения работы.
- При чистке сохранять ключевые вехи (даты, решения, договорённости), убирая второстепенные детали.
- Поддерживать файл компактным и актуальным.
